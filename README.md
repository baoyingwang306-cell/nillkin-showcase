# 📄 NILLKIN 悍能无畏 - 高级交互展示页说明文档

## 📌 项目概述

本项目是一个专为“NILLKIN 悍能无畏”键盘保护套打造的**高级商业互动落地页**。
页面采用了业界前沿的 **Scrollytelling（滚动叙事）** 技术，复刻了类似苹果官网的极简高级感。通过用户的上下滚动，精准控制 3D 渲染序列帧的播放、文字的视差浮现以及轮播图的滑动，提供沉浸式的产品浏览体验。

## ✨ 核心技术特性

1. **纯净序列帧引擎 (Canvas Sequence)：** 放弃笨重的视频解码，采用纯图片序列帧在 `<canvas>` 上绘制，实现绝对零延迟、正反向拖拽如丝般顺滑的 60fps 动画。
2. **移动端高清防糊适配 (DPR High-Res)：** 自动侦测设备物理像素比（Device Pixel Ratio），在高端手机（如 iPhone Retina 屏）上动态放大渲染画布，彻底解决 Canvas 默认拉伸导致的画面发虚问题。
3. **分段排队预加载 (Batched Preloading)：** 针对 750 张庞大序列帧的网络加载噩梦，采用“VIP 通道优先加载前 30 帧保障秒开，剩余 720 帧后台 5 张/组慢速排队静默下载”的策略，大幅降低首屏白屏时间。
4. **纯内存性能优化：** 将昂贵的 DOM 节点尺寸和位置查询在初始化时进行全局缓存，滚动引擎 (`renderLoop`) 内仅作纯数学运算，彻底消除“布局抖动 (Layout Thrashing)”。

## 📂 文件夹结构与素材规范

代码对图片素材的命名和路径有严格要求，**请务必严格遵守大小写**（云端服务器区分大小写）：

```text
根目录/
├── index.html               # 主网页代码
├── README.md                # 本说明文档
└── assets/                  # 静态资源总目录
    ├── logo.png             # 顶部导航栏 Logo
    ├── H-d-2.png            # 电脑端首屏静态背景图
    ├── mode1.jpg ~ mode4.jpg # 底部滚轮展示区的 4 张产品图
    │
    ├── a000.webp ~ a749.webp # 👉 【电脑端】3D 序列帧 (共750张)
    │
    └── mobile/              # 📱 移动端专用资源库
        ├── H-d-2.webp       # 移动端首屏竖版静态图
        └── a_000.webp ~ a_749.webp # 👉 【移动端】3D 竖版序列帧 (共750张)

```

### 💡 设计输出建议：

* **序列格式：** 强烈建议使用 `.webp` 格式导出，在保持高级光影质感的同时，单张体积控制在 `50-100KB`。
* **移动端尺寸：** 宽度务必达到 `1080px` 或 `1170px` 以上，以喂饱目前的高刷视网膜屏幕。

## ⚙️ 核心参数配置指南

如果你后续重新渲染了 3D 动画，帧数发生了变化，只需要修改 `index.html` 底部 `<script>` 标签开头的几个核心变量即可：

```javascript
// ==========================================
// 1. 核心配置参数
// ==========================================
// 修改这里的数字，以匹配你实际的序列帧首尾编号
const startFrame = 0;   // 起始帧编号
const endFrame = 749;   // 结束帧编号

// 如果你更改了图片格式或命名规则，在这里修改：
const framePath = (index) => {
    // padStart(3, '0') 确保数字是 3 位数，如 001, 042, 749
    const paddedIndex = String(index).padStart(3, '0');
    if (window.innerWidth <= 768) {
        return `assets/mobile/a_${paddedIndex}.webp`; // 手机端路径
    } else {
        return `assets/a${paddedIndex}.webp`;         // 电脑端路径
    }
}; 

// 滚动阻尼感（缓冲滑顺度）
// 数值越小，跟随越迟缓越平滑；数值越接近1，越生硬直接。默认最佳体验为 0.12。
const easeAmount = 0.12; 

```

## 🎨 样式修改指南 (CSS)

如果你需要调整排版或颜色，可通过检索以下注释区块定位到 CSS 对应位置：

* `/* 2. 顶部固定导航栏 */`：修改 Logo 大小、导航文字颜色。
* `/* 3. 静态首屏 Hero Section */`：修改第一屏的主标题大小、文字渐变色 (`.text-gradient-wuwei`)。
* `/* 4. 沉浸式 3D 滚动序列特效区 */`：修改滚动过程中悬浮文字的字体大小。
* `/* 7. 移动端适配 */`：如果你发现某一段文字在手机上挡住了产品，请在这里找到对应的 `.text-section:nth-child(X)`，调整 `padding-top`、`margin-top` 即可精准控制每一屏的文字落点。

## 🚀 发布与调试避坑指南

1. **大文件上传：** 本项目的图片总数超过 1500 张（双端），请**绝对不要**在 GitHub 网页端直接拖拽上传。请务必使用 **GitHub Desktop（桌面版客户端）** 进行 `Commit` 和 `Push`。
2. **手机端缓存幽灵：**
部署更新后，手机浏览器极易缓存旧版本导致白屏或错乱。测试最新代码时，**请务必使用手机浏览器的“无痕模式 / 隐身模式”** 粘贴网址进行访问。
3. **国内网络部署建议：**
GitHub Pages 免费好用，但由于海外节点特性，国内首次加载可能会出现几秒延迟。如正式对真实消费者发布，建议将本项目代码和 `assets` 文件夹完整迁移至**阿里云 OSS** 或 **腾讯云 COS**，并配置国内独立域名，即可实现真正意义上的瞬间“秒开”。
